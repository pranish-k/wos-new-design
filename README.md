# wos-new-design

A rebuild of [wforce.org](https://wforce.org), the site for Workforce Opportunity Services, moving it off WordPress onto Next.js 16.
Same content and information architecture as the original site, with a new front end and design system.

**Live preview:** [wos-new-design.vercel.app](https://wos-new-design.vercel.app)

## Stack

- Next.js 16 (App Router), React 19, TypeScript in strict mode
- Tailwind CSS v4, with every color and font token in one `@theme inline` block in `app/globals.css`
- No UI component libraries and no other runtime dependencies

## What's in it

- Pages for the full wforce.org site: services, partners, programs, locations, financials, blog, contact and donate
- A sitemap and robots file generated by the app
- Content pulled from a mirror of the original WordPress site

## Run it locally

```sh
npm install
npm run dev
```

Then open http://localhost:3000.
